# Carroots

An educational word-building game developed in **Unity** and **C#** during the **Global Game Jam Pärnu 2023**.

Players grow carrots by planting **word stems** (roots) and expanding them using **prefixes** and **suffixes**. Successfully constructing valid words allows plants to grow, increasing their value before harvesting them for coins.

The project combines word formation mechanics with resource management to create an engaging educational experience focused on vocabulary development.

---

# Gameplay

Players start with a limited amount of money and a collection of word stems.

The gameplay loop consists of:

1. Planting a root word.
2. Applying prefixes or suffixes.
3. Building valid words.
4. Growing the plant (The word).
5. Harvesting the plant (The word) for coins.
6. Repeating the process until the winning condition is reached or the player runs out of resources.

The game encourages experimentation with word construction while introducing basic resource management mechanics.
